## 🌟 About the Event

DevFest Prayagraj 2026 brings together developers, students, researchers, and tech enthusiasts from across Northern India to the historic Sangam city. The conference spotlights breakthroughs in:

- **Agentic AI & Machine Learning**: Autonomous agents, LLMs, and intelligent systems
- **Google Cloud & Infrastructure**: Serverless, scalable backends, Kubernetes, and DevOps
- **Android & Mobile**: Modern Android development, Kotlin Multiplatform, and Jetpack Compose
- **Web & Open Ecosystem**: Progressive Web Apps, modern performance standards, and frameworks

## 🛠️ Tech Stack

- **HTML5**: Semantic structure, accessibility (`aria-*`), JSON-LD Event metadata for rich search results.
- **CSS3**: Custom design tokens, CSS Grid, Flexbox, responsive typography, and Google DevFest 2026 official palette.
- **JavaScript**: Pure Vanilla ES6+ without external library dependencies for ultra-fast load times.
- **Assets**: Optimized `.webp` and `.woff2` font formats for high-performance delivery.

## 💻 Getting Started

You can run the site locally using any static web server:

### Python
```bash
# From devfest-prayagraj-2026 folder
cd devfest-prayagraj-2026
python -m http.server 8000
```
Then navigate to `http://localhost:8000`.

### Node.js (npx)
```bash
cd devfest-prayagraj-2026
npx serve
```
